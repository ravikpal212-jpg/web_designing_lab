Apache virtual host example:

<VirtualHost *:80>
    ServerName collegeweb.local
    DocumentRoot "C:/xampp/htdocs/collegeweb"

    <Directory "C:/xampp/htdocs/collegeweb">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>

Add to Windows hosts file:
127.0.0.1 collegeweb.local

Then restart Apache.

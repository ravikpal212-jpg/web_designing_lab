MCA108P - Lab Sheet 4
21 PHP / Apache / MySQL Programs

Files:
Q01.php through Q21.php

Q03, Q04 and later database programs assume MySQL is running and use:
Database: college_db
User: root
Password: empty (default XAMPP setup)

If your MySQL password is different, edit Q04.php.

Support files:
students.sql       -> creates college_db and students table
users.sql          -> creates users table for Q12
virtual-host.txt   -> Apache virtual host configuration
mysql-user.sql     -> restricted database user configuration

Place PHP files in your Apache document root (for example XAMPP htdocs)
and open them through http://localhost/.

Q13 creates an uploads directory automatically.

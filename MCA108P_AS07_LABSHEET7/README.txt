MCA108P - LAB SHEET 7
Online Bookstore Project

Q01.php to Q21.php are separate programs/tasks.
Supporting files:
db.php
Q02.sql
Q05_login.php
style.css
validation.js

Setup:
1. Start Apache and MySQL using XAMPP/WAMP.
2. Import Q02.sql into phpMyAdmin.
3. Edit db.php if your MySQL username/password differs.
4. Put all files in one Apache htdocs folder.
5. Open Q01.php through http://localhost/...

Q05 creates accounts with password_hash().
Q06 uses $_SESSION['cart'].
Q07 records orders and decreases stock in a transaction.
Q08/Q09/Q21 are admin-only examples.
Q18 demonstrates client-side JavaScript validation.
Q20 is a manual end-to-end testing checklist.

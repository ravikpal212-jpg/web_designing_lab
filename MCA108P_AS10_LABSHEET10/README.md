# Web Designing — Lab Sheet 10

Contains separate files for Q01–Q20. File types reflect the exercise: PHP, SQL, Git commands, Apache configuration, and text notes.

## Notes
- Q01–Q02 are Git command exercises; replace the GitHub repository URL with your own.
- PHP examples that use a database expect a `db.php` file defining a PDO connection.
- Configure PHP, Composer/PHPMailer, Apache modules, TLS and database credentials before running the related tasks.
- These are educational starter examples; don't deploy placeholder credentials or tokens.
